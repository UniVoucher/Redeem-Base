Privacy Policy

1. No Data Storage

Redeem Base does not store any user data. We do not require account registration and do not maintain databases of user information.

2. What We Don't Collect

We do not collect, store, or retain:

  • Personal information or identities
  • Card secrets or private keys
  • User accounts or profiles
  • Transaction histories
  • Email addresses or contact information

3. Temporary Processing

When you redeem a card, we temporarily process:

  • Card ID and recipient address (discarded after transaction)
  • Card secret (never stored, used only for decryption)

This information is processed in memory only and is not saved to any database or log files.

4. Third-Party Services

Our service interacts with external services that have their own privacy policies:

  • UniVoucher API for card verification
  • Blockchain networks for transaction processing
  • Alchemy for blockchain connectivity

5. No Data to Delete

Since we don't store user data, there is no personal information to request or delete. Each transaction is processed independently without data retention.

6. Contact

For questions about this privacy policy, please contact us through our GitHub repository.
